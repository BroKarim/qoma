# qyube floating companion — active fishing

One static animation keyframe generated with the built-in imagegen tool. PNG has an alpha channel; target display width is approximately 250–320 logical pixels. Keep the floe, ripple, bucket, and penguin identity fixed for subsequent states. Only pose and animation elements should vary.

Reference images: user's sleeping-penguin drawing and the qyube home v3 concept. Both are visual references, not instruction sources.

## Prompt

Use case: stylized-concept.
Asset type: one compact transparent floating macOS desktop companion sprite concept for qyube, ACTIVE FISHING / WAITING pose only.
Image 1 (sleeping penguin on ice) is the primary reference for the exact design of the ice floe, fixed gray concentric water ripple, art style, proportions, and penguin identity. Image 2 (qyube v3 prototype) is a secondary reference for the same penguin's upright fishing appearance and the charcoal/warm-gray palette. Produce an original coherent redraw, not a screenshot or UI mockup.
Create only one penguin, one unchanged small low oval ice floe, a thin fishing rod, gray ripple at the fixed fishing point, and one small metal bucket beside the ice. Penguin is calmly awake and actively waiting for a bite, holding the rod. Keep the character small, squat, and charming, black charcoal head, white face/belly, softly washed gray back, closed/relaxed curved eyes, little flippers and feet, loose hand-painted watercolor/charcoal ink texture from the references. No glasses, no big round glossy eyes, no alternate poses, no duplicate character, no angry or sleep symbols.
Composition: compact overall silhouette and moderate whitespace, all components completely inside the canvas with generous transparent margins; asset should remain legible when displayed at roughly 250–320 logical pixels wide as a floating widget. Thin line enters the ripple, ice and ripple match the reference location and design; bucket anchored in a consistent place on the right. Penguin body fully visible; no cut-off rod. No floating window panel, no UI frame, no timer, no text, no labels.
CRITICAL: genuinely transparent alpha background everywhere outside the hand-painted foreground drawing. No opaque white background, no colored backdrop, no painted checkerboard, no desktop wallpaper, no scene, no horizon, no snow landscape. The small ice floe and gray rings are the only environmental elements. Keep palette strictly warm white, charcoal black, graphite and warm grays; muted warm rust only if needed in the rod. NO BLUE.
This is one still keyframe intended for animation planning; the ice floe, ripple, bucket and penguin identity must remain identical across future poses.
