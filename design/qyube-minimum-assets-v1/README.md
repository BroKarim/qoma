## Confirmed catch behavior

`fishing / normal bite wait → bite → reel → direct bucket deposit → immediately cast and fish again`

- One generic fish image represents all fish during floating animation.
- One tree-shaped token represents all non-fish catches during floating animation; it is not a new collectible definition.
- Both follow the same continuous catch-to-bucket path. No hand-held reveal, celebratory hold, or pause after landing, including rare/new discoveries.
- Award only on bucket landing, preserving the existing five-active-minute banking rule.
- Immediately reenter casting/fishing after landing. The normal randomized 6–10 second in-water wait for a new bite remains; do not add a separate cooldown.
- Catalog and Fishing Report show the real collectible identity and art.

## Review and implementation limits

- Visually inspected: eight poses in each variant, round glasses on each pose in variant B, nine shared properties/effects, no penguin cast-shadow or scenic background.
- PNG metadata confirms alpha on all three sheets. Check matte edges over both dark and light desktops before shipping.
- The generated grid is a visual arrangement, not exact crop metadata. Some rod gestures extend beyond nominal equal-cell boundaries. Do not split these images using equal-size tiles; define padded per-pose bounds after approval.
- Props have independent display scales on the sheet. Sheet spacing and relative sizes are not scene coordinates.
- A generated floe is a visual match to the reference, not a pixel-identical extraction. Approve its silhouette before promoting it to the fixed production master.
- Rods/lines are baked into some pose examples even though standalone versions are also supplied. These are pose guides; separate head, flippers, eyes, body, rod and line with pivots for smooth animation. Avoid doubling the baked rod when assembling a rig.
- No source layers, production anchors, animation clips or native implementation are claimed by this batch. The next step is to choose the character variant and turn accepted art into registered layers for one continuous fishing loop.
