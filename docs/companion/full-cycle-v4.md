# Full fishing cycle v4

Implemented on `codex/companion-watercolor-animation`.

The actual SpriteKit companion now plays arrival → casting → idle → bite → pull/reward → deposit → recast. The six-second preview shortens the idle wait to 0.8 seconds; normal sessions retain their 6–10 second wait. `full-cycle-v4.gif` loops the light/dark comparison, and `full-cycle-v4.mp4` contains the 30 FPS render.

## Assets

Built-in imagegen produced two new twelve-drawing atlases using the approved catch artwork as identity/style reference:

- `Qoma/Assets.xcassets/Companion/CompanionCastFramesV4.imageset/CompanionCastFramesV4.png`
- `Qoma/Assets.xcassets/Companion/CompanionDepositFramesV4.imageset/CompanionDepositFramesV4.png`

Exact prompts are saved in `cast-v4-prompt.txt`, `deposit-v4-prompt.txt`, and `deposit-v4-layout-prompt.txt`. Per-frame feet anchors and body heights compensate for differences in generated margins. Two deposit cells use custom crop rectangles to preserve a long rod without including the neighboring character. A small SpriteKit warp compresses only the far-right rod margin in those poses so it remains inside the existing 140 pt panel.

## Runtime

Arrival fades the shared base and settles the character onto the ice. Casting uses twelve drawings, continuous line travel, and a small landing splash. Deposit lasts 1.2 seconds: the catch rises on the left, clears the head horizontally, then drops on the bucket's x coordinate. The bucket gives a small squash response at landing, and the character returns to its fishing orientation before recasting. Early release also uses the deposit drawings in reverse. Decorative catches never award persisted catalog items.

Reduce Motion retains stable drawings and catch visibility without the arrival slide, casting travel or bucket squash. Existing pause and distraction control still interrupt the cycle. The separate distraction artwork is not regenerated by this change.

Reproduce the preview with the Debug app's `--companion-snapshots <directory>` argument. The `full-cycle` subfolder contains 180 PNG frames at 30 FPS.

Validation: CompanionPlaybackTests and DistractionIntegrationTests passed. New checks cover all twelve cast/deposit drawings, decorative reward accounting, and the catch route around the head into the bucket. Final build succeeded. Arrival, casting and deposit frames were inspected on light/dark backgrounds; the final rod correction was checked in the renderer. Long-session manual use has not been checked.
