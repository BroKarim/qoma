## a-ice-panorama

Use case: ui-mockup. Generate ONE polished landscape macOS qyube Analytics screen prototype, front-on, highly legible, full window. NO second heatmap card, no large separate Focus Activity heading, no visible horizontal scrollbar at this desktop width. Metrics describe only selected day, not all-time totals; no streaks or percentages.
Below this unified card, Daily Breakdown with side-by-side Top Apps and Top Websites lists and muted blue bars: Xcode 45m, Safari 25m, Notes 15m; github.com 15m, developer.apple.com 10m. Bottom edge shows Daily Catches section beginning with small watercolor fish. Readable calm spacious practical UI, subtle borders, restrained paper texture only in illustration, no photorealistic 3D. Main banner moderately shallow so metrics and heatmap fully visible.
